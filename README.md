# Site Nice Crochet 🧶

Une plateforme web moderne dédiée à Nice Crochet, permettant de présenter les formations, les collections de vêtements au crochet et les services proposés.

## ✨ Fonctionnalités

- Page d'accueil
- Présentation de Nice Crochet
- Catalogue des formations
- Collection de produits
- Détails des formations
- Interface responsive
- Navigation fluide avec React

## 🛠️ Technologies utilisées

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- HTML5

## 📂 Installation

Clonez le projet :

```bash
git clone https://github.com/VOTRE-UTILISATEUR/site_Nice_crochet.git
```

Accédez au dossier :

```bash
cd site_Nice_crochet
```

Installez les dépendances :

```bash
npm install
```

Lancez le projet :

```bash
npm run dev
```
